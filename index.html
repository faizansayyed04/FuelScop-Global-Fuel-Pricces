About the project

Project brief

Global Fuel Prices & Taxation Trends

This project studies how retail fuel prices vary across countries and how those patterns sit alongside movements in the global crude-oil market. It brings together country-level views of petrol and diesel prices with Brent crude context, using Tableau to make comparisons easier to explore.

The website is the presentation layer for the analysis. The embedded dashboard remains the source for chart-level exploration; the surrounding sections explain the project scope, questions and interpretation limits.

How to read this project

Scope & methodology

A clear view of what the analysis covers—and what should be checked before drawing conclusions.

Analysis scope

  • Country-level fuel price comparisons across 84 countries.
  • Petrol, diesel and LPG categories.
  • Trend period: 2020 to 2026, as defined by the project dataset.
  • Brent crude series used as broader market context.

Interpretation notes

Fuel prices can be influenced by crude oil markets, exchange rates, transport costs, local supply conditions and government taxes or subsidies. A relationship in the charts does not, by itself, prove that one factor caused another.

Always check the dataset's units, update frequency, missing values and country coverage before comparing values or making claims.
